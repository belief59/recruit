# 지원서 이력 맞춤 도우미 — 실행 방법

PC에 앱으로 설치해 쓰는 웹앱(PWA)입니다. 따로 설치할 프로그램은 없습니다.

## 웹에서 바로 쓰기 (Vercel)
- 주소: **https://recruit-livid-psi.vercel.app/**
- GitHub `main`에 푸시하면 Vercel이 자동으로 배포합니다. 위 주소를 Chrome·Edge로 열고 **⬇ 앱 설치**를 누르면 로컬 서버 없이 설치됩니다.
- 앱은 정적 페이지라 **이력 데이터는 서버에 저장되지 않고** 각자 브라우저에만 남습니다. 주소마다 저장 공간이 따로라서, 로컬(`localhost:5179`)에서 쓰던 이력은 **백업 내보내기 → 웹 주소에서 불러오기**로 옮기세요.

## 로컬에서 실행·설치
1. **`실행.bat` 더블클릭** → 작은 로컬 서버가 백그라운드에서 켜지고, 기본 브라우저(Chrome/Edge)에서 `http://localhost:5179` 가 열립니다.
2. 오른쪽 위 **⬇ 앱 설치** 버튼(또는 주소창 오른쪽의 설치 아이콘)을 누릅니다.
3. 이후에는 **바탕화면·시작 메뉴의 "이력 도우미"** 아이콘으로 엽니다. 별도 창으로 열리고, **서버가 꺼져 있어도(오프라인) 동작**합니다.

## 업데이트
- 앱 파일(`index.html` 등)이 바뀌면 `실행.bat`을 한 번 실행한 뒤 앱을 열면 새 버전이 반영됩니다.
- 서버는 30분 동안 요청이 없으면 스스로 꺼집니다. 서버는 이 PC 안에서만 접속되며, 앱 파일 외에 폴더의 다른 파일(PDF·JSON 등)은 보내지 않습니다.

## 데이터 저장
- 입력한 이력은 **그 브라우저(앱)에** 저장되어 다시 열어도 남아 있습니다.
- 주소(`http://localhost:5179`)가 같아야 같은 데이터가 보입니다. 예전처럼 `index.html`을 직접 열어 입력한 데이터는 앱에서 보이지 않으니, 그 화면에서 **백업 내보내기** → 앱에서 **불러오기** 하세요.
- 브라우저 기록 삭제·PC 교체에 대비해 상단 **백업 내보내기**로 JSON 파일을 받아 두세요.

## AI 추천
- **Claude 앱 Artifact로 열면** API 키 없이 Claude가 추천합니다.
- **로컬 파일로 열면** 우측 상단 **⚙ 설정**에 Anthropic API 키를 넣어야 AI 추천이 됩니다(사용량만큼 요금 발생).
- 키가 없거나 호출이 실패하면 **태그·키워드 일치 정렬**로 대신하고, 화면에 그 사실을 표시합니다.

## 파일·폴더 가져오기 (이력서·증빙서류·논문)
1. ① 이력 보관함에서 **파일·폴더 가져오기** → 파일 선택 / **폴더 선택**(하위 폴더 포함) / 끌어다 놓기
   - 읽는 파일: 일반 PDF, **스캔 PDF**, **한글(.hwp·.hwpx)**, **워드(.docx·.doc)**, 사진(JPG·PNG·WEBP 등), 인터넷 바로가기(.url)
   - 논문 링크나 DOI는 입력란에 한 줄에 하나씩 붙여 넣어도 됩니다.
2. 문서 종류를 자동으로 구분해 정리합니다: 이력서·지원서, 경력증명서, 성적증명서, 학위·졸업증명서, 수료증, 자격증, 어학성적표, 상장, 논문
   - 종류가 틀렸으면 "읽은 파일" 목록에서 고르면 그 파일만 다시 정리합니다. **원문** 버튼으로 인식된 글자를 볼 수 있습니다.
3. **같은 이력은 하나로 합칩니다.** 값이 서로 다르면 **증빙서류 값이 우선**하고, 한쪽에만 있는 값(학점·자격번호·정확한 날짜 등)은 채웁니다.
   - 보관함에 이미 있는 이력과도 비교해 "기존과 통합"으로 표시하고, 무엇이 바뀌는지 보여 줍니다.
   - 증빙서류로 확인된 이력에는 **증빙✓** 표시가 붙습니다.
4. 확인·수정 후 **반영**합니다.

- **스캔·사진의 글자 인식은 이 PC 안에서** 처리합니다(외부 전송 없음). 처음 한 번 인식 엔진과 한국어 데이터(약 15MB)를 내려받고, 이후에는 오프라인에서도 됩니다. 쪽마다 몇 초씩 걸립니다.
- 스캔 품질이 낮거나 표가 복잡하면 글자가 틀릴 수 있으니 반영 전에 꼭 확인하세요.
- DOI가 있는 논문은 Crossref에서 제목·저자·학술지·날짜를 채웁니다(DOI만 보냄, 끌 수 있음).
- 글자로 된 이력서 PDF는 선택하면 AI로 분류할 수 있습니다(API 키 필요). 스캔·사진에서 인식한 내용은 AI로 보내지 않습니다.
- 한글·워드 파일은 본문 글자와 **표(행·칸 구조)**를 이 PC 안에서 읽습니다(한컴오피스·워드 설치 불필요). 문서 안에 붙여 넣은 **그림(스캔 이미지)** 속 글자는 읽지 않으니, 그런 문서는 PDF로 저장하거나 그림만 따로 넣으세요.
- 읽지 못하는 파일: 암호가 걸린 문서, 한글 **배포용(읽기 전용) 문서**(앞부분 미리보기만 읽음), 한글 97 이하에서 만든 옛 .hwp(한글 2002 이상 형식만 읽음), HEIC 사진.

## 만료·하위 급수 자동 제외
- **유효기간이 지난 어학성적·자격**: 만료일(유효기간)을 적은 경우 그 날짜, 어학성적은 적지 않으면 **시험일로부터 2년**(TOEIC·TOEFL·IELTS·TEPS·OPIc·HSK·TSC·JPT 등)이 지나면 제외합니다. JLPT·DELF처럼 기한이 없는 시험은 그대로 둡니다. 증빙서류에 "유효기간"이 적혀 있으면 가져오기 때 자동으로 채웁니다.
- **하위 급수 자격**: 같은 종목에서 더 높은 급수를 가지고 있으면 낮은 쪽을 제외합니다. (예: 컴퓨터활용능력 1급 ↔ 2급, 정보처리기사 ↔ 정보처리산업기사 ↔ 정보처리기능사)
- **같은 시험의 낮은 성적**: 유효한 성적 중 가장 좋은 것 하나만 남깁니다. (예: HSK 6급 ↔ 5급, TOEIC 여러 번)
- 제외된 이력은 **삭제되지 않고** 보관함에 "제외: 사유"로 표시되며, ② 추천·③ 결과 복사·도우미 창에서 빠집니다. 도우미 창에서는 "만료·하위 급수도 보기"로 잠시 볼 수 있습니다.
- **⚙ 설정 → 이력 자동 제외**에서 끌 수 있습니다.

## 입사지원 사이트에서 쓰기 — 도우미 창
1. 앱 오른쪽 위 **📋 도우미 창**을 누르면 좁은 창이 화면 오른쪽에 열립니다. (설치한 앱 아이콘을 오른쪽 클릭 → "도우미 창"으로도 열 수 있습니다.)
2. 회사 지원서 화면을 왼쪽에 두고, 도우미 창에서 **학교·전공·입학일·학점·자격번호 같은 칸을 하나씩 눌러 복사** → 지원서 입력칸에 붙여 넣습니다.
   - 위쪽에서 날짜 표기(2023.05 / 2023-05-12 / 20230512 등)를 지원서 양식에 맞게 고르세요.
   - 검색, 항목 바로가기, "②에서 선택한 이력만" 보기를 쓸 수 있고, **한 줄 복사**는 ③에서 고른 양식으로 복사합니다.
3. 메인 창에서 이력을 고치면 도우미 창에도 바로 반영됩니다.

## 사용 순서
1. **① 이력 보관함**: **파일·폴더 가져오기**, **일괄 입력**(엑셀에서 복사해 붙여넣기), 또는 항목별 추가로 등록하고 태그를 답니다.
2. **② 지원서 맞춤**: 기관명·직무명·공고 본문을 넣고 **추천 받기** → 관련도 "상"은 자동 체크, 필요에 따라 조정합니다.
3. **③ 결과 복사**: 양식(가형/나형 또는 기관별 양식)을 고르고 **전체 복사** 또는 항목별·줄별 복사를 합니다.
   기관별 양식은 **다른 이름으로 저장**으로 만듭니다.
4. 웹 입사원서처럼 칸이 나뉜 양식은 **📋 도우미 창**에서 칸별로 복사합니다.
